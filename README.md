A tiny Python program (standard library only, no network) that writes a single safety warning label for every human being to `/output/entry.txt`. Written like the sign on an exhibit tank — do not tap the glass — the human inside is easily startled, overthinks everything, and cries at dog food commercials. Funny first, plausible second, with the laugh landing in the last few words.

> WARNING: Do not tap the glass. Human is easily startled, overthinks everything, and cries at dog food commercials.

The entry is one line, 114 characters, within the 160-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
